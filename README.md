## Research and tooling themes

- AI security tooling for real developer workflows, not demo-only scanners.
- Local-first analysis with explicit operator control and no silent model fallback.
- Evidence-backed findings: source-to-sink paths, reproducible proof, and patch validation.
- MCP and Claude Code security, including tool abuse, prompt injection, and agent boundary testing.
- Security automation that produces portable artifacts: SARIF, Markdown reports, PR comments, and structured JSON.
